## Model-core 公共脚本留出集

当前默认 model-core 从 2,000 份公共作业中筛出 541 份简单关卡脚本，覆盖 147 个关卡和 240 名干员。`main_01-07` 在 `action_samples.jsonl`、`train.jsonl` 和 `valid.jsonl` 中均为零条，确保 `1-7` 实战不泄漏进训练或离线验证。

当前模型在 293 个验证决策组上得到：top-1 `44.37%`、top-3 `78.50%`、top-5 `90.44%`、top-10 `96.25%`，平均正样本排名 `2.82`，pairwise accuracy `94.65%`。10,281 行候选全部通过结构验证。

自由生成固定检查继续覆盖训练集外公共作业；生成结果必须通过 BattleDSL 与 MAA validator，且动作引用的干员全部属于玩家干员库。训练集外的 `1-7` 已使用 MAA `v6.14.1` 演习三星，作为默认模型提升依据。
