# v2 算法边界

## 可以做什么

- 从真实关卡数据提取敌人、路线、部署格和 15 秒压力窗口。
- 使用锁定 GameData 构建的数值模型估算常态 / 爆发 / 周期 DPS、EHP、治疗、控制和范围交集。
- 使用 200 份作业编译的聚合先验评价动作形态，不检索或复制原作业。
- 用确定性 Beam Search 比较候选。
- 使用真实 `killed / total` 反馈排除失败 hash 或复用成功脚本。

## 不能证明什么

- `candidateScore` 不是通关率或预计歼灭率。
- 协议验证 `100/100` 只表示结构合法。
- 复杂技能、召唤物、特殊索敌和条件机制只记录覆盖缺口，不伪造精确结果。
- 生成结果不是 MAA 实际执行结果。

## 失败策略

v2 没有旧生成器或职业基线 fallback。模型缺失、schema 不兼容、候选搜索为空或协议验证失败时直接返回错误。达到 1200 ms deadline 且已有合法候选时返回 best-so-far；没有合法候选仍报错。

## 数据覆盖

`combatCoverage` 表示已部署干员具备基础数值模型；`skillCoverage` 表示技能结构化覆盖程度，无法确认的机制写入 `coverageGaps`。默认 E2 满级、技能 10、潜能 1、无模组、满信赖只用于排序，不写入 MAA `requirements`。
