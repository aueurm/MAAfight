# v2 算法边界

## 可以做什么

- 从真实关卡数据提取敌人、路线、部署格和 15 秒压力窗口。
- 使用静态属性估算 DPS、EHP、治疗和阻挡压力。
- 使用 200 份作业编译的聚合先验评价动作形态，不检索或复制原作业。
- 用确定性 Beam Search 比较候选。
- 使用真实 `killed / total` 反馈排除失败 hash 或复用成功脚本。

## 不能证明什么

- `candidateScore` 不是通关率或预计歼灭率。
- 协议验证 `100/100` 只表示结构合法。
- 职业基线不能替代干员技能、天赋、模组、召唤物和关卡机制模拟。
- 生成结果不是 MAA 实际执行结果。

## 失败策略

v2 没有旧生成器 fallback。模型缺失、候选搜索为空或协议验证失败时直接返回错误，避免输出来源不明的脚本。

## 数据覆盖

`combatCoverage` 表示本次候选中使用精确干员静态数据的比例。使用职业基线时必须输出覆盖缺口；内部默认基线不得写入 MAA `requirements`。
