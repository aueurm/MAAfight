裁剪范围为 1280 × 720 画面的 `x=50..480`、`y=270..440`，解压后为 431 × 171 × 3 字节。原像素的 B、G、R 均不低于 220 时保留为白色，其余归零；不包含玩家信息或完整游戏画面。

- `mission-failed-title`：明亮地图上的“任务失败 / MISSION FAILED”。
- `login-title`：登录页的 Rhodes Island 图案，作为反例。
- `formation-title`：编队页，作为反例。

样本来自本项目 2026 年 7 月的本机演习截图。测试将同一标题放到明亮与暗色背景，确保地图亮度不会改变失败判断。它们只验证国服当前固定布局，不代表所有客户端、分辨率或未来 UI。
